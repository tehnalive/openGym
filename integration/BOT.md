# Telegram launcher — TG04

Отдельный процесс на **Node.js 22+**, без npm-зависимостей. При приватной команде `/start` (включая deep-link аргумент) или `/app` отвечает кнопкой Telegram `web_app`. Группы, каналы, редактирования, другие сообщения и неразрешенные пользователи игнорируются. Команды вида `/app@botname` не обрабатываются: в приватном чате используйте `/app`.

## Переменные окружения

| Переменная | Контракт |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Обязательный серверный секрет BotFather; формат `положительный_ID:секрет` (20–200 символов `A-Za-z0-9_-`). Не размещать в Mini App, Git, Docker build args или образе. Передавать процессу при запуске. |
| `TELEGRAM_MINI_APP_URL` | Обязательный абсолютный **HTTPS** URL опубликованного Mini App, без user/password. HTTP не разрешен даже для localhost. Не размещать секреты в URL. |
| `TELEGRAM_ALLOWED_IDS` | Необязательный список положительных безопасных целых Telegram user ID через запятую; пробелы вокруг элементов допускаются. Например `12345,67890`. Если переменная отсутствует, доступ открыт всем; если задана пустой или неверно — процесс останавливается. Для личного пилота задайте ID обоих участников. |

Allowlist ограничивает только кнопку в этом боте. Доступ к самому приложению и API должен отдельно проверять сервер по Telegram auth; отправка кнопки не является авторизацией API. Это должен быть тот же бот, чьим токеном backend проверяет `initData`.

## Запуск

Из корня репозитория с уже переданными переменными окружения:

```text
node integration/telegram-bot.mjs
```

В Docker запускайте эту команду отдельным сервисом с Node 22+ и передавайте секрет во время запуска. В этой стадии Docker-конфигурация и openGym не изменяются. Процесс требует исходящего HTTPS к `api.telegram.org`; входящий порт для бота не нужен. Mini App должен быть доступен телефону пользователя по HTTPS.

До запуска настройте Mini App своего бота в BotFather. Лаунчер не вызывает `setWebhook`, `deleteWebhook`, `setChatMenuButton` и не меняет настройки бота. Вначале выполняется только `getWebhookInfo`: если webhook уже есть, процесс останавливается с объяснением. Удаление webhook — отдельное явное действие администратора. Запускайте только **один** polling-процесс на токен. Конфликт Telegram 409 или ошибка авторизации 401 останавливают процесс.

## Поведение и ограничения

- Используется long polling `getUpdates` с timeout 30 секунд; сетевой лимит запроса — 40 секунд. Никаких приветствий всем пользователям при старте, автоматических напоминаний или итогов тренировок. `sendMessage` вызывается только в ответ на распознанную приватную команду человека.
- Offset увеличивается после успешного ответа либо намеренного игнорирования update; подтверждается последующим `getUpdates`. Обновления в пакете сортируются, дубликаты пропускаются. Сетевые ошибки, 429 и 5xx повторяются с задержкой; при 429 учитывается `retry_after` (до 3600 секунд). Другие ошибки останавливают процесс, не теряя текущий update намеренным подтверждением.
- Доставка **не exactly once**: если Telegram принял сообщение, но ответ потерялся, повтор может создать вторую кнопку. Offset хранится в памяти; при перезапуске Telegram может повторно доставить еще не подтвержденный update. Постоянный checkpoint не реализован. Старые накопленные команды Telegram также могут быть обработаны — это по-прежнему ответы на команды, не рассылка.
- SIGINT/SIGTERM прерывают запрос и ожидание повтора; процесс завершается нормально. При остановке посреди отправки текущий update может остаться неподтвержденным.
- В логах только фиксированные диагностические сообщения; исходные HTTP-ошибки, Telegram description, токен, тела ответов и URL запросов не печатаются. Не включайте внешнее HTTP debug-логирование с токеном в URL.

## Проверка без Telegram

```text
node --test integration/telegram-bot.test.mjs
```

Тесты подменяют `fetch`, не загружают реальные секреты и не обращаются к Telegram. Проверяют конфигурацию, allowlist, приватность команд, webhook-конфликт, offset и дубликаты, повтор после сетевой ошибки, 429, скрытие секретов и остановку long poll. Импорт модуля сам по себе не запускает бот.
