# Отправка программы другу (TG19)

Кнопка **План → Поделиться в Telegram** создаёт на сервере копию программы (только тренировки, расписание и свои упражнения; ни истории, ни веса, ни настроек) и открывает выбор чата Telegram со ссылкой вида

```text
https://t.me/Gym_statsbot/app?startapp=p_<id>
```

Друг нажимает ссылку, Mini App открывается и показывает «Тренировка от <имя>: N упражнений, дни…» с кнопками «Добавить в мои программы» и «Закрыть».

## Что нужно сделать в BotFather (один раз)

Ссылка вида `t.me/<бот>/<имя>` работает только для Mini App, зарегистрированного с коротким именем.

1. В @BotFather: `/newapp`, выбрать бота `@Gym_statsbot`.
2. Название и описание любые; картинка 640×360 и GIF обязательны для мастера (можно пропустить GIF командой `/empty`).
3. URL Mini App: тот же адрес, что в `TELEGRAM_MINI_APP_URL` (`https://gym.cringe.monster/`).
4. Короткое имя (short name): `app`. Тогда ссылка `https://t.me/Gym_statsbot/app` работает.

Если короткое имя другое, задайте его в `TELEGRAM_MINI_APP_SHORT_NAME`. Если нужно обойтись без `/newapp`, оставьте переменную пустой (`TELEGRAM_MINI_APP_SHORT_NAME=`): ссылка станет `https://t.me/Gym_statsbot?startapp=p_<id>` и откроет главное Mini App бота (его задаёт BotFather: `/mybots` → бот → Bot Settings → Configure Mini App). Такая ссылка в чате показывает кнопку «Открыть», а не открывается сразу.

## Переменные окружения API

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `TELEGRAM_BOT_USERNAME` | `Gym_statsbot` | Имя бота без `@` (5–32 символа `A-Za-z0-9_`). Неверное значение заменяется на умолчание. |
| `TELEGRAM_MINI_APP_SHORT_NAME` | `app` | Короткое имя Mini App; пусто — ссылка на главное Mini App бота. |
| `SHARE_TTL_DAYS` | `0` | Срок жизни ссылки в днях; `0` — ссылка не истекает. |
| `SHARE_MAX_PER_USER` | `100` | Сколько ссылок у одного профиля. |

Фронтенду переменные не нужны: готовую ссылку отдаёт сервер.

## Поведение

- Ссылка открывает программу **любому вошедшему пользователю, у кого она есть**, в том числе если сообщение переслали дальше. Перед созданием приложение предупреждает об этом. Автор виден как отображаемое имя профиля; Telegram ID не отдаётся.
- Ссылка работает всегда (по умолчанию срока жизни нет; его можно включить через `SHARE_TTL_DAYS`). Если отправить ту же программу ещё раз, получится та же ссылка. Кнопки отзыва в приложении нет; маршрут `DELETE /api/shares/{id}` остаётся в API. Удаление профиля удаляет его ссылки.
- Повторное открытие работает всегда. Программа не дублируется: добавленные тренировки помечаются `sharedFrom`, при повторе приложение пишет «уже добавлена».
- Если ссылка открыта новым пользователем, у которого идёт первый запуск, превью появится сразу после него (чтобы не прерывать настройку).
- Лимиты: 10 новых ссылок в час на профиль, 120 чтений в минуту, до 200 КБ, 50 тренировок и 600 упражнений на ссылку.
- Сервер проверяет только форму файла программы; полный разбор (`parsePlan`) делает приложение получателя: неизвестные упражнения отбрасываются, остальное добавляется через `mergePlan`.
- Вне Telegram кнопка копирует ссылку.

Проверено только автотестами (`api/test/shares.test.js`, `frontend/src/lib/plan-link.test.js`, `frontend/src/components/SharedPlan.test.jsx`); живой Telegram не использовался.
