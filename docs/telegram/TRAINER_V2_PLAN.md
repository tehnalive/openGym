# Кабинет тренера, шаг 2: план четырёх функций

Дата: 03.11.2026. Основа: [COMPETITORS.md](COMPETITORS.md) и дополнительное исследование справки TrueCoach, Everfit, Fitsly (ссылки в разделах). Реализация: разделы 14–17 [TRAINER_MODE.md](TRAINER_MODE.md).

## Организация работы

- Две дорожки в отдельных worktree, внутри дорожки функции идут последовательно, дорожки параллельно:
  - A (`claude/tg14-lane-a`): пауза и архив → соблюдение плана (расчёт исключает дни паузы).
  - B (`claude/tg14-lane-b`): метка «записал тренер» → шаблоны и копирование рутин.
- На функцию: агент-владелец (Sonnet; plan → код → тесты → раздел в документации), затем независимый ревьюер (Sonnet, high, только чтение). Замечания возвращаются автору.
- Оркестратор сливает дорожки, прогоняет все наборы (`api`, `frontend`, проверки локалей, `fork:check`, сборка) и выкладывает.

## 1. Метка «записал тренер»

**У конкурентов.** Fitsly: состояние «Logged by coach» и баннер на результате, клиент видит «тренер сейчас ведёт занятие» и не может начать ту же тренировку. У TrueCoach, Everfit, Trainerize метка автора в справке не описана.

**Как у нас.** Тренер пишет в дневник только подопечного без Telegram (весь документ, этап 1.6). Записи в дневник подопечного с Telegram у тренера нет, поэтому блокировка двойной записи не нужна, пока не появится право записи.

**План.**
1. Сервер ставит `via: 'coach'` и `by` новым и изменённым тренировкам при записи тренером (`PUT /api/trainer/managed/{id}/data`). Клиент поставить метку не может, существующие метки сохраняются.
2. Бейдж «Записал тренер» в истории и просмотре тренировки (обычное приложение и экраны тренера).
3. Метка переживает экспорт и импорт копии.
4. Тесты: серверное правило, отсутствие ложных 409, бейдж.

## 2. Соблюдение плана 7/30/90

**У конкурентов.** TrueCoach: три процента 7/30/90 у клиента, панель Needs Attention при падении на 20%. Fitsly: выполненные запланированные / запланированные за 30 дней, потолок 100%, сегодняшний день не считается, «Gone quiet» после 7 дней без тренировок. Everfit: представления списка At risk, No activity (14 дней), Paused; после паузы считается с даты возобновления.

**План.**
1. Чистая функция на сервере: запланировано = дни расписания связи (`link.schedule.days`) в окне до вчерашнего дня, не раньше начала связи, без дней паузы; выполнено = запланированные дни с тренировкой плюс тренировки вне плана как перенос, не больше запланированного. Сегодня входит, только если тренировка уже есть.
2. Без расписания процента нет («нет плана»), показывается число тренировок за окно.
3. `GET /api/trainer/clients` отдаёт `compliance` и `daysSinceLast` только при открытой истории.
4. Кабинет: в строке 30 дней и «был N дн. назад», цвет ≥80 зелёный, 50–79 жёлтый, ниже красный. Флаг «Нужно внимание»: нет тренировок 7 дней (кроме паузы) или 7-дневный ниже 30-дневного на 20 п.п. Такие подопечные сверху. На экране подопечного 7/30/90 с «выполнено из запланированного».
5. Подопечному процент не показывается (как у TrueCoach).

## 3. Шаблоны тренера и копирование рутин

**У конкурентов.** TrueCoach: Programs, назначение нескольким клиентам, переключатель Sync, копирование тренировки клиент → клиент и клиент → программа. Everfit: Program Library, Save to Library, Assign Program нескольким клиентам с датой начала, дальше копия клиента правится отдельно. Hevy Coach: Copy Program to Client.

**План.**
1. Шаблон: имя, заметка, набор рутин и нужные им пользовательские упражнения. Хранится на сервере отдельным файлом тренера. Создаётся из своих рутин тренера (в его обычном «Плане» есть полный редактор) или из рутин подопечного без Telegram.
2. Назначение копией, без связи с шаблоном (как Everfit; Sync позже). Подопечному без Telegram рутины пишутся сервером в дневник. Подопечному с Telegram сервер документ не пишет: приходит предложение «Тренер прислал программу», подопечный принимает его в своём приложении, и рутины добавляет его собственное приложение.
3. Копирование рутины подопечному: с экрана подопечного без Telegram, «Скопировать другому» и «В шаблоны».
4. Кабинет: экран «Шаблоны», назначение с выбором нескольких подопечных.

## 4. Пауза и архив подопечного

**У конкурентов.** Everfit: Pause coaching с датой возврата (по умолчанию 7 дней) и причиной, вкладка Paused, Resume сразу или с даты; архив не учитывается в подписке, реактивация одним действием. TrueCoach: архив сохраняет данные, клиент не может войти, вернуть можно переключением в active.

**План.**
1. Пауза: место сохраняется, доступ сохраняется, напоминания не идут, соблюдение плана не считает эти дни. Пресеты 1 неделя, 2 недели, месяц, без срока; причина чипами. Автоматическое окончание по дате.
2. Архив: связь `archived`, место освобождается, доступ тренера к данным закрыт, данные остаются у подопечного. Возврат проверяет лимит 5. Подопечный с Telegram видит статус и может завершить связь; другого тренера, пока связь в архиве, не принимает.
3. Кабинет: «Подопечные 3 из 5», приглушённые строки на паузе, раздел «Архив (N)» внизу с «Вернуть».
